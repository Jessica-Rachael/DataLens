Drop in a CSV and see what's inside it.

DataLens profiles your file, checks its quality, runs the standard exploratory analyses and draws the charts that fit each column. No code needed.

  • Column types detected automatically: numbers, categories, dates, IDs and free text.
  • Data quality: missing values, duplicates, invalid entries and inconsistent spellings.
  • Statistics: mean, median, mode, spread, quartiles, skewness and kurtosis.
  • Relationships: correlation heatmap, scatter plots, pivot tables and cross-tabs.
  • Time series: trends, moving averages, seasonal patterns and unusual periods.
  • Outliers by the IQR and Z-score methods, with box plots.

Column profiles

The type DataLens detected for each column decides which analyses and charts are used for it.

Summary statistics

Descriptive statistics for every numeric column. Skewness above +1 or below −1 means a long tail on one side; kurtosis above 0 means heavier tails than a normal distribution.

Distributions

Histograms show how values are spread. The solid line marks the mean and the dashed line the median.

Categories

Frequency of each value in categorical columns. Pie charts are added only where there are eight or fewer categories.

Correlation

Correlation runs from −1 (move in opposite directions) to +1 (move together). Pearson measures straight-line relationships; Spearman measures any consistently rising or falling relationship. It shows association, not cause and effect.

Pivot table

Summarise a numeric column for each group, or count rows per group.

Cross-tabulation

A contingency table counts how often each combination of two categories occurs. The chi-square test checks whether the two columns are independent; Cramér's V (0 to 1) shows how strong the association is.

Time series

Values are grouped into periods (resampled) to show the trend. The moving average smooths short-term ups and downs. Each point is labelled with the first day of its period.

Outliers

IQR method: a value is an outlier if it lies more than 1.5 × IQR below the first quartile or above the third quartile. Z-score method: a value is an outlier if it lies more than 3 standard deviations from the mean. Outliers are not always errors; check them before removing anything.
